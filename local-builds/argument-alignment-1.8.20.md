# Сопоставление аргументов — 1.8.20

Предыдущая версия сравнивала весь текст изменённой строки. В замене одного аргумента на два перевод значения снижал сходство `name="Params"` с `name="Основное"`. Более похожее значение соседнего `code="inputs_and_outputs"` могло даже перехватить пару у `name="Inputs and Outputs"`. Старое правило для одинаковых типов операторов покрывало только одинаковое число строк.

Новый приоритет задаётся неизменной целью присваивания/именем аргумента, оператором и отступом. При наличии соответствующей цели на другой стороне соседнее поле с похожим значением не получает эту пару. Правило действует также при расширении уже найденных пар и заполнении промежутков. Сам текст и порядок строк не меняются.

Приоритет ограничен однозначными простыми и dotted targets. Повторяющиеся имена без достаточных опор, типизированные и индексированные цели сохраняют прежний способ сопоставления. Лимиты сравнений не увеличены. Режим `matching=none` сохраняет позиционное поведение; оба блока со скриншота проверены и в нём.

## Проверки

- Браузерный пример воспроизводил обе ошибки на 1.8.19. Теперь `name` находится напротив `name`; добавленный `code` — отдельной строкой ниже. Добавлены обратная замена и вставка перед целевым аргументом.
- 940 тестов / 47 suites прошли, включая проверки сохранности обеих сторон diff и прежних проблем с импортами, конструкторами и условиями. TypeScript, ESLint, форматирование и production build прошли.
- 20 browser-сценариев на реальном bundle: 12 новых комбинаций (две раскладки × три режима matching × два направления) и восемь прежних. Проверены номера, исходный текст, геометрия пар и отдельные строки для добавленного/удалённого `code`.
- Независимое ревью проверило операторы, отступы, комментарии, строки, повторы и перестановки; блокирующих замечаний нет.

Публичные синтетические результаты и скриншоты: `argument-alignment-1.8.20/`. Browser-снимок использует fallback syntax palette, а не language server пользователя. В baseline-снимке старый harness не задавал класс тёмной темы; геометрия ошибки от этого не зависит.

## Повторение

Node.js 22, npm и Playwright/Chromium:

```sh
npm ci
npm test -- --runInBand
npm run build:prod
npx tsc --noEmit -p tsconfig.json
npm run format:check
node integration/browser/line-alignment.cjs
npx vsce package --no-dependencies --githubBranch main -o local-builds/diff-viewer-1.8.20-argument-alignment.vsix
```

`tested-assets.json` содержит SHA-256 проверенных bundle и CSS; при упаковке их байты сверены с VSIX.
