# Проверка отображения и интерфейса — 1.8.15

Проверка разделена на сохранность исходных данных, удобство расположения замен и реальные действия пользователя. Один счётчик unit-тестов не заменяет эти проверки.

Итог: **732 теста в 43 наборах прошли**; TypeScript, ESLint и production-сборка прошли. Полный нефильтрованный desktop-прогон в VS Code **1.139.0**: **28 из 28 групп прошли**, ошибок браузера нет. [JSON-отчёт с хешами bundle](ui-controls-final3/report.json) и [снимок меню](ui-controls-final3/filename-context-menu.png) относятся к той же сборке, которая включена в VSIX.

## Отображение

- Корпус содержит 27 специально подобранных и 40 детерминированных сгенерированных примеров. Каждый проходит цепочку parse → realign → render в двух раскладках и трёх режимах matching: 402 сочетания.
- Проверяются точный текст обеих сторон, номера строк, EOF-маркеры, имена файлов, число вставок/удалений, неизменность входных данных и повторяемость выравнивания.
- Примеры включают одиночные и целые переписанные блоки, полностью изменённые имена/значения, импорты, повторяющийся код, перемещения, несколько hunks, пустые/добавленные/удалённые файлы, переименования и Git-quoted пути.
- Строки одного типа оператора с одинаковым отступом теперь сравниваются рядом даже при полной замене операндов. Уже выбранные упорядоченные совпадения не пересекаются. Комментарии, отдельные литералы и несовместимые роли проверяются отрицательными примерами.
- Combined merge с несколькими родителями автоматически открывается исходным текстом с пояснением. Двухколоночный renderer не способен корректно представить все его стороны, поэтому такое представление больше не используется.

Это проверка поддерживаемых форматов и конкретных инвариантов, а не обещание единственного идеального расположения строк для любого произвольного текста.

## Исправленные действия интерфейса

- Имя файла выделяется обычным кликом/перетаскиванием и копируется, не переключая редактор. Для открытия используются Ctrl/Cmd+клик, Enter или Open file.
- Copy path работает и без доступного локального исходника. В меню заголовка есть Copy file name и Copy file path.
- Copy selected text сохраняет текст на правом pointerdown: Chromium очищает выделение до события contextmenu. Проверяется содержимое системного буфера обмена после выбора команды.
- В readonly diff нет Cut/Paste. В редактируемом поле поиска эти команды сохранены и проверяются настоящим Cut → clipboard → Paste.
- Collapse/Expand/Find до готовности webview и во время redraw больше не теряются. Viewed, нажатый во время обновления, сохраняется только для неизменённого содержимого файла.
- Горизонтальное колесо и Shift+wheel работают над общей полосой прокрутки.

## Реальная проверка кнопок

`integration/desktop/ui-controls.cjs` управляет установленным VS Code через Playwright/CDP в отдельном профиле. Используются настоящие клики, клавиши, меню VS Code и системный clipboard; исходное содержимое clipboard восстанавливается. `window.menuStyle=custom` позволяет проверить собственное меню VS Code через accessibility DOM. Пустой список пунктов нативного macOS-меню не засчитывается как успех.

Проверяются:

1. Выделение имени, обычное копирование, Copy path, Copy file name/path/selected text из меню, отсутствие Cut/Paste в readonly.
2. Summary show/hide и переход к файлу; Viewed, Expand all, смешанное состояние и счётчик.
3. Syntax highlighting, Find, регистр, предыдущий/следующий результат, Enter/Shift+Enter/Escape, закрытие, отсутствие результатов, редактируемое меню поля поиска.
4. Toolbar Collapse/Expand, обе раскладки, Raw, Diagnostics, Explorer Open collapsed.
5. Раскрытие контекста сверху/снизу по 20 строк и остаткам в обеих раскладках.
6. Локальная прокрутка, общая полоса: клик, drag, wheel и Shift+wheel.
7. Open file, Ctrl/Cmd+клик/Enter по имени, переход на строку, Open old/Open new переименованного файла.
8. Уведомление о большом diff, раскрытие 150 файлов, отключённые элементы пустого diff.

Финальный JSON-отчёт содержит версию VS Code, SHA-256 обоих bundle, отсутствие фильтра и результаты каждой группы. Промежуточные диагностические прогоны не подменяют финальный полный прогон.

## Повторение

Из корня репозитория с Node.js 22:

```sh
npm ci
npm test -- --runInBand
npm run build:prod
npx tsc --noEmit -p tsconfig.json
DIFF_UI_AUDIT_PHASE=final node scripts/test-ui-controls-desktop.mjs
```

Для desktop-теста нужны установленный VS Code и Playwright. `VSCODE_EXECUTABLE` задаёт путь к Code; `DIFF_UI_AUDIT_OUTPUT` задаёт каталог отчёта. Runner создаёт временный профиль и workspace. Синтетический корпус находится в `src/shared/testing/diff-contract-corpus.ts`, проверки — в `src/shared/__tests__/diff-contract.test.ts`. Проверки очередности действий находятся в `src/extension/provider/__tests__/action-lifecycle.test.ts`.

Контекстное меню использует штатный механизм [VS Code Webview API](https://code.visualstudio.com/api/extension-guides/webview#context-menus).
