# Повторная проверка — 1.8.16

Проверены последовательности действий и патчи настоящего Git. Ошибки ниже сначала воспроизведены на 1.8.15, затем проверены после исправления.

| Сценарий                                                         | До                                                                       | После                                                                       |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| Refresh / тема / изменение файла после горизонтальной прокрутки  | `scrollLeft 430 → 0`                                                     | `430 → 430` для всех открытых панелей                                       |
| Смена раскладки                                                  | Строка 66 сменялась строкой 72 или 60 при сохранении пиксельного scrollY | Строка 66 остаётся на той же высоте экрана                                  |
| Один вручную открытый файл в большом diff                        | Refresh закрывал его; `scrollY 1612 → 257`                               | Открытым остаётся только выбранный файл; `1612 → 1612`                      |
| Активный результат Find после смены раскладки                    | Счётчик `1 / 1`, но результат выше экрана: `y=-2904`                     | Результат сохраняет позицию `y=380.8`                                       |
| Поздний реальный SemanticTokensProvider                          | Выделение очищалось, Cmd+C оставлял старый clipboard                     | Выделение `selected_token = 12` сохраняется и копируется точно              |
| Git path с пробелами                                             | Служебный TAB попадал в имя и расширение                                 | Точный путь без delimiter; буквальный TAB внутри имени сохранён             |
| Буквальные имена `(working tree)`, `(abcdef0123)`, `{old → new}` | Повторная нормализация меняла настоящий путь                             | Метаданные обрабатываются при parsing; decoded path больше не преобразуется |
| CR внутри исходной строки                                        | Терялся текст после CR; могли появиться ложные строки патча              | Текст, номера и CR сохраняются в модели и DOM                               |
| Изменение CR → без CR и обратно                                  | Upstream intraline regex подмешивал текст другой стороны                 | Для такой группы отключены только intraline spans; обе стороны точны        |

## Доказательства и охват

- 29 сохранённых патчей сгенерированы `git diff --no-index` и `--find-renames`; before/after записаны независимо от парсера. Проверяются имена, source projections, EOF, обе раскладки DOM и CRLF транспорт патча.
- Отдельные 16 комбинаций CR addition/removal × split/unified × lines/words × syntax off/on сначала падали и затем прошли. Проверяется, что соседняя обычная группа по-прежнему получает intraline-подсветку.
- Проверены прямое, обратное и многострочное выделение, а также отсутствие лишней замены узлов при одинаковых токенах.
- Полный unit-набор: 863 теста в 45 suites. TypeScript, ESLint и production-сборка проходят.
- Desktop Find и semantic-selection проверяются в установленном VS Code с отдельным профилем, настоящим provider, реальным меню и системным clipboard. Предыдущее содержимое clipboard восстанавливается.
- На окончательной сборке прошли обе последовательные desktop-проверки и все 28 групп полного UI-прогона, без ошибок браузера. [Отчёт последовательностей](sequence-copy-find-fixed/report.json), [полный UI-отчёт](ui-controls-1.8.16/report.json), [браузерный отчёт о позициях](view-state-1.8.16/view-state-results.json).

## Повторение

Из корня репозитория с Node.js 22:

```sh
npm ci
npm test -- --runInBand
npm run build:prod
node integration/browser/view-state.cjs /tmp/diff-viewer-view-state
node integration/browser/carriage-return.cjs
DIFF_SEQUENCE_ONLY='find-active|semantic' node scripts/test-sequence-copy-find.mjs
DIFF_UI_AUDIT_PHASE=final node scripts/test-ui-controls-desktop.mjs
```

Генерация независимых Git fixtures: `node scripts/generate-git-source-fidelity-fixtures.mjs`. Browser-проверкам нужны Playwright и Chromium; desktop-проверкам нужен установленный VS Code, путь можно передать через `VSCODE_EXECUTABLE`.

Исходный файл diff не изменяется. Combined merge по-прежнему открывается текстом, потому что в нём больше двух версий. Проверка покрывает приведённые сценарии; она не означает отсутствия любых возможных ошибок на произвольных данных.
